# Flutter Portfolio Web App

Live Demo:
https://mldineshreddy-dotcom.github.io/portfolio/

## Overview
A responsive cross-platform portfolio web application designed to present professional projects, technical competencies, and academic background.

## Features
- **Responsive Layout:** Works smoothly on desktop, tablet, and mobile browsers.
- **Interactive Navigation:** Seamless view switching between home, about, and project showcases.
- **Project Catalog:** Highlights core software development and machine learning projects.

## Tech Stack
- **Framework:** Flutter / Web Technologies
- **Hosting:** GitHub Pages
